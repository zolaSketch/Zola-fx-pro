# የቲክቶክ ፕሮፋይል ባነር (Profile Banner / Background) — ሙሉ መመሪያ

> በላክከው ስክሪንሾት ላይ ያለው ሰፊው ፎቶ — ከስምህ፣ ከ@username እና ከአቫታር ጀርባ ያለው — ቲክቶክ **Profile Background** (ተጠቃሚዎች "banner" ብለው ይጠሩታል) ይባላል። ይህ መመሪያ ምን መሆኑን፣ አካውንታችሁ ላይ እንዳለ እንዴት እንደምትፈትሹ፣ እንዴት እንደምትጭኑ፣ ትክክለኛ መጠን/ዲዛይን እና ፊቸሩ ገና ካልተከፈተላችሁ የሚሰራውን የመፍትሄ መንገድ ይሸፍናል።

> ⚠️ በስክሪንሾቱ ላይ ያለችው ሰው ፎቶ የሌላ ሰው አካውንት ነው። ያንን ፎቶ/ስም/አካውንት በእናንተ አካውንት ላይ መጠቀም የ**ግለሰብ ማስመሰል (impersonation)** እና የቅጂ መብት ጥሰት ነው። የራሳችሁን ፎቶ/ብራንድ ተጠቀሙ።

## 1. በምስሉ ላይ ያለው ባነር ምንድን ነው?

- ከአቫታር፣ ከስም፣ ከ@username፣ ከFollowing/Followers ቁጥር እና ከ bio ጀርባ የሚታየው **ሰፊ ፎቶ** ነው። (ከYouTube channel banner ጋር ይመሳሰላል።)
- በቲክቶክ መተግበሪያ ውስጥ **"Change background"**, **"Add background"** ወይም **"Banner"** በሚል ስም በ **Edit profile** ገጽ ላይ ይገኛል።
- ይህ በስክሪንሾት ላይ የተቀየረ/የተለጠፈ ነገር አይደለም — እውነተኛ የቲክቶክ ፊቸር ነው።
- ግን ቲክቶክ ይህን በይፋ አላስተዋወቀውም፤ በድረ-ገጹ ላይም አልተመዘገበም። በ2026 ወራት ውስጥ **ተከታታይ በሆነ መንገድ (staged rollout)** ለተወሰኑ አካውንቶች እየተከፈተ ነው። ስለዚህ አንዳንድ ሰዎች ላይ አለ፣ በእናንተ ላይ ገና ላይኖር ይችላል።

## 2. አካውንታችሁ ላይ ፊቸሩ አለ? (10 ሰከንድ ፍተሻ)

1. TikTok ን ከ App Store / Google Play **አዘምኑ** (የመጨረሻው ስሪት)።
2. መተግበሪያውን **ሙሉ በሙሉ ዘግተው እንደገና ክፈቱ**።
3. `Profile` (ከታች ቀኝ) → ✏️ **`Edit profile`** (ወይም ከስም አጠገብ ያለው እርሳስ) ይጫኑ።
4. ከላይ አካባቢ **`Change background` / `Add background` / `Banner`** የሚል አማራጭ ይመልከቱ።

**ካለ** → ወዲያውኑ መጠቀም ትችላላችሁ (ክፍል 3)።
**ከሌለ** → አካውንታችሁ ገና በተከፈተው ቡድን ውስጥ አልገባም ማለት ነው።

## 3. እንዴት እንጭነው (ደረጃ በደረጃ)

1. `Profile` → ✏️ `Edit profile` ይጫኑ።
2. **`Change background` / `Add background`** ን ይጫኑ።
3. **`Upload photo`** ይምረጡ → ከጋለሪያችሁ ፎቶ ይምረጡ (ወይም "Choose from your posts" ካለ፣ ካለፈው ቪዲዮ ላይ ፍሬም መውሰድ ይችላሉ)።
4. ፎቶውን **drag / pinch** አድርገው አስተካክሉ — ዋናው ነገር (ፊት፣ ሎጎ፣ ጽሑፍ) በ**መሃል** እንዲቀመጥ ያድርጉ።
5. **`Save` / `Done`** ይጫኑ።
6. ወደ `Profile` ተመልሰው ውጤቱን ይመልከቱ። በተለያዩ ስልኮች ላይ ትንሽ ልዩነት ሊኖር ስለሚችል፣ በሌላ ስልክም ተመልክተው ያረጋግጡ።

**ማስታወሻ፦** ባነር በ**ሞባይል መተግበሪያ** ላይ ብቻ ይታያል፤ በኮምፒውተር ድረ-ገጽ (tiktok.com) ላይ ላይታይ ይችላል። ስለዚህ ውጤቱን በስልክ መመልከት ያስፈልጋል።

### ዝግጁ ቴምፕሌቶች (በዚህ ፎልደር ውስጥ)

| ፋይል | ለምን |
| --- | --- |

| `banner-template-3posts-3240x1440.png` | በ3 ፒን የተደረገ ባነር ለመስራት (ክፍል 7) |

**`banner-maker.html` ን እንዴት እንከፍተው፦** ፋይሉን በብራውዘር ብቻ መክፈት ይቻላል (ምንም መጫን አያስፈልግም)። ወይም በተርሚናል፦

```bash

# ከዚያ ክፈት: http://localhost:8000/banner-maker.html
```

**እንዴት እንደሚጠቀሙበት፦** ቴምፕሌቱን በCanva/Photoshop/PixelLab ከፍተው፣ የራሳችሁን ፎቶ ከታችኛው ሌየር አድርገው ያስቀምጡ፣ ቴምፕሌቱን ደግሞ ~20% ግልጽ (opacity) አድርገው ያስቀምጡ። ሲጨርሱ ቴምፕሌዩን ሰርዙ ወይም ደብቁ።

## 5. በስክሪንሾቱ ላይ ያለውን መልክ ለማምጣት — የዲዛይን ምክሮች

1. **አንድ ጥሩ ፎቶ ይምረጡ** — ከስክሪንሾቱ ላይ ያለው ሞቅ ያለ የቡና ቤት/ሬስቶራንት ቀለም ያለው ፎቶ ነው። ከብራንዳችሁ ጋር የሚስማማ ቀለም ይምረጡ።
2. **ፊት/ርዕሰ-ጉዳዩን በመሃል-ላይ ያስቀምጡ** — ታችኛው ክፍል በስምና በግሬዲየንት ይሸፈናል።
3. **ታችኛው ግሬዲየንት ይጨምሩ** — ከግማሽ በታች ጥቁር ወደ ግልጽ (linear gradient) አድርጉ። ይህ ስሙ እንዲነበብ ያግዛል፣ እና በስክሪንሾቱ ላይ እንዳለው የሚመስል ያደርጋል።
4. **ጽሑፍ አታስቀምጡ** (ወይም በጣም ጥቂት) — ስሙ እና @username አስቀድመው በላዩ ላይ ይጻፋሉ። ጽሑፍ ካስፈለገ በ**ቀኝ-ላይ** ወይም **መሃል** ብቻ።
5. **ንጹህ፣ ጠንካራ ኮንትራስት** — በስልክ ላይ ባነሩ ትንሽ ነው፤ ብዙ ዝርዝር አይታይም።
6. **የቀለም ስርዓት** — 2-3 ቀለሞች ብቻ (ለምሳሌ ጥቁር + ብርቱካን + ነጭ)።
7. **ብሎር ከሚያስፈልግ** — ፎቶው በጣም ዝርዝር ከሆነ፣ በላዩ ላይ ጥቁር 20-30% overlay ጨምሩ።
8. **አቫታርን አብሮ አስቡ** — አቫታር በቀኝ በኩል ስለሚቀመጥ፣ በዚያ ቦታ ዋና ነገር አታስቀምጡ።
9. **የስልክ ስክሪን ስፋት ይለያያል** — ጠርዞችን 10% "የማይታይ" ብለው ያስቡ።

## 7. ፊቸሩ ገና ካልተከፈተላችሁ — የ"3 ፒን ፖስት" ዘዴ (ለሁሉም አካውንት ይሰራል)

ይህ የቲክቶክ ፊቸር አይደለም፤ ነገር ግን **የፕሮፋይል ግሪድ የላይኛው ረድፍ** ላይ 3 ፖስቶችን በማስተካከል አንድ ሰፊ ምስል ያስመስላል።

### ደረጃ 1 — ሰፊ ምስል አዘጋጁ
- መጠን፦ **3240 × 1440 px** (ማለትም 2.25:1)
- `banner-template-3posts-3240x1440.png` ን መሰረት ያድርጉ።
- ሰው ፊት፣ ጽሑፍ ወይም ሎጎ በ**መገጣጠሚያው (seam)** ላይ አታስቀምጡ — በ x=1080 እና x=2160 ላይ ይቆራረጣል።

### ደረጃ 2 — ወደ 3 ቁርጥራጮች ክፈሉ
- እያንዳንዱ **1080 × 1440 px** (3:4)።
- በTikTok ውስጥ የሚለጠፈው የ1080×1920 ፖስት **መሃል 1080×1440** ብቻ ስለሚታየው፣ እያንዳንዱን ቁርጥራጭ በ**1080×1920** ካንቫስ መሃል ላይ አስቀምጡ (ላይና ታች ጥቁር/ብሎር ይሙላ)።
`banner-maker.html` ይህን ራሱ ያደርግላችኋል ("3 tiles" ቁልፍ)።

### ደረጃ 3 — በትክክለኛው ቅደም ተከተል ፖስት ያድርጉ
| ቅደም ተከተል | የሚለጠፈው ቁርጥራጭ |
| --- | --- |
| 1ኛ | **ቀኝ** ቁርጥራጭ |
| 2ኛ | **መሃል** ቁርጥራጭ |
| 3ኛ | **ግራ** ቁርጥራጭ |

ምክንያቱ፦ ቲክቶክ አዲሱን ፖስት **ከላይ-ግራ** ስለሚያስቀምጥ፣ ግራ ቁርጥራጩ መጨረሻ ላይ መለጠፍ አለበት።

### ደረጃ 4 — ሦስቱንም ፒን ያድርጉ
- **ቀኝ** ፖስት → ⋯ → `Pin` (**መጀመሪያ**)
- **መሃል** ፖስት → `Pin` (**ሁለተኛ**)
- **ግራ** ፖስት → `Pin` (**መጨረሻ**)
- የመጨረሻ ፒን የሆነው ከላይ-ግራ ስለሚታየው፣ ውጤቱ **ግራ → መሃል → ቀኝ** በትክክል ይነበባል።

### ማስጠንቀቂያዎች
- ቲክቶክ **3 ፒን** ብቻ ይፈቅዳል። ሌላ ፖስት ለመፒን ከፈለጋችሁ ባነሩ ይሰበራል (እንደገና መስራት አለባችሁ)።
- በተለያዩ ስልኮች/ስሪቶች ላይ የግሪድ መቁረጫ ትንሽ ይለያያል — ፊትና ጽሑፍ ከመገጣጠሚያው ያርቁ።
- "Pinned" መለያ እና የቪው ቁጥር በፎቶዎቹ ላይ ይታያሉ — ከላይና ከታች ነገር አታስቀምጡ።
