# የቅዳሴ መልመጃ አፕ (Kidasse Memorization App)

የኢትዮጵያ ኦርቶዶክስ ተዋሕዶ ቤተ ክርስቲያን የቅዳሴ መለማመጃ (memorization) አፕሊኬሽን — የእሁድ ቅዳሴን እና በጾም ወቅት ቀን የሚቀደሰውን ቅዳሴ ለመማርና ለመልመድ።

## ✨ ባህሪያት (Features)

- **ሁለት የቅዳሴ ሥርዓቶች** — ☀️ የእሁድ ቅዳሴ (ዜማ፦ ግዕዝ/አራራይ) እና ✝️ የጾም ቅዳሴ (ዜማ፦ ዕዝል)።
- **ክፍል በክፍል ማለመድ** — እያንዳንዱ የቅዳሴው ክፍል (መክፈቻ፣ ጸሎተ አኰቴት፣ ሃይማኖት፣ ሳንቅቱስ፣ አቡነ ዘበሰማያት...) በቅደም ተከተል።
- **ቋንቋ መቀየሪያ** — ግዕዝ / አማርኛ / ላቲን ትራንስሊትሬሽን / እንግሊዝኛ በነጠላ ቁልፍ ማብራት ወይም ማጥፋት።
- **4 የመልመጃ ሁነታዎች**
  - 🎧 **ንባብ** — በተለመደ መንገድ ማንበብ
  - ✨ **አሳይ** — ቀስ በቀስ መግለጥ (line-by-line reveal)
  - 🎯 **ማድመቅ** — የአንድን መስመር ብቻ ማየት፣ የቀረው ደብዛዛ
  - 🙈 **ደብቅ** — ቃል በቃል ጠቅ በማድረግ መግለጥ (word-by-word memory game)
- **🗣 ንባብ (ድምጽ)** — የመሣሪያውን የንግግር ቴክኖሎጂ በመጠቀም ጸሎቱን ያነባል።
- **⏬ አውቶማቲክ ማሸብለል** — ፍጥነት በመቆጣጠር ቀጣይነት ያለው ማንበብ።
- **🧠 ፈተና (Quiz)** — ቁልፍ ጸሎቶችን ለማስታወስ ባለብዙ ምርጫ ጥያቄዎች።
- **📊 ሂደት ክትትል** — የተለመዱ ክፍሎች፣ ጠቅላላ ጊዜ፣ ተከታታይ ቀናት (streak)።
- **🔖 ምልክቶች** — የሚፈለጉ ክፍሎችን ማስታወስ።
- **🎨 ገጽታ** — ብርሃን / ጨለማ / ሴፒያ + የፊደል መጠን መቆጣጠር።
- **📱 PWA** — ወደ መጫን የሚቻል፣ ከመስመር ውጭ (offline) የሚሠራ።
- **⌨️ የቁልፍ ሰሌዳ ድጋፍ** — ⬇ / → / Space / Enter ለቀጣይ መስመር።

## 🗂 የፋይል መዋቅር

```
kidase-app/
├── index.html          ዋናው ገጽ
├── style.css           ቅጦች
├── app.js              የአፕሊኬሽኑ አመክንዮ
├── data.js             የቅዳሴ ጸሎት ውሂብ (ግዕዝ + አማርኛ + ላቲን + እንግሊዝኛ)
├── manifest.webmanifest  PWA ማኒፌስት
├── sw.js               Service Worker (offline)
├── serve.py            የማስተናገጃ ስክሪፕት
└── *.png               አዶዎች
```

## 🚀 ለማስኬድ

```bash
cd kidase-app
python3 serve.py 8080
```

ወደ አሳሽዎ `http://localhost:8080` ይሂዱ።

## ⚠️ ማሳሰቢያ (አስፈላጊ)

ይህ የቅዳሴ ጸሎት የተሰበሰበው ለትምህርትና ለመልመጃ ዓላማ ነው።
**ለትክክለኛው እና ለጸደቀው የቅዳሴ ሥርዓት በቤተ ክርስቲያን የታተመውን መጽሐፈ ቅዳሴ (Missal) ይጠቀሙ።** ጸሎቶቹን ከጸደቀ ምንጭ ጋር አነጋግሮ ማረጋገጥ ይመከራል።
