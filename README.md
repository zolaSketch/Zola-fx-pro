# Zola-fx-pro

እንኳን ደህና መጡ — welcome to the Zola-fx-pro monorepo, home of ZOLA-brand
open-source tools built for the Amharic-speaking world first, everyone second.

## 🧬 [marketdna/](marketdna/) — ZOLA MarketDNA
The world's first **Amharic-first quant intelligence lab**. AI learns market
regimes (the market's "weather") and breeds trading strategies with genetic
evolution, validated by walk-forward out-of-sample testing — with a built-in
"honesty report" so fake backtests can't fool you.

```bash
cd marketdna && python3 server.py   # pure stdlib, zero dependencies
```

## ⛪ [kidase/](kidase/) — ቅዳሴ መልመጃ
A mobile-first PWA for practicing the Ethiopian Orthodox *ሥርዓተ ቅዳሴ*
(liturgy) with reading, practice, flash and quiz modes.

```bash
cd kidase && python3 serve.py
```
